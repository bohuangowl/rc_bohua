# 设计要求 & 交互规则（For Codex）
## 1. 作业背景
本次为 Service 设计作业，主题：**企业内部统一 HTTPS 通知投递服务**。
需要你配合完成：需求理解、系统设计、代码实现、代码测试。最终产出 README、Python MVP 代码、测试用例。

## 2. 原始业务需求
### 2.1 业务场景
企业内部多个业务系统发生关键事件时，需要调用外部供应商提供的 HTTPS API 发送通知：
1. 用户通过第三方广告引流并注册成功 → 通知对应广告系统
2. 用户订阅付款成功 → 通知 CRM 系统更新联系人状态
3. 用户完成商品购买 → 通知库存系统变更库存

### 2.2 外部 API 差异
不同供应商 API 存在差异：请求地址不同、请求 Header / Body 格式不同。

### 2.3 业务约束
1. 上游业务系统**无需关心外部 API 返回值**
2. 核心目标：保证通知请求**稳定、可靠送达**目标地址

### 2.4 系统目标
设计并实现一个内部服务：接收内部业务系统的 HTTP 通知请求，可靠地转发投递至外部目标 API。
